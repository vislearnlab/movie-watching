Notes

Open this file directly (file:// — double-click it, or drag it into a browser tab). Do NOT serve it with python3 -m http.server: Python's built-in http.server doesn't support HTTP Range requests (confirmed by testing -- it returns the whole file regardless of the requested range), which breaks video seeking entirely over that route. Local file:// playback doesn't have this problem, since the browser reads the file directly rather than negotiating byte ranges over HTTP.

Progress is auto-saved to this browser's local storage as you go, but that storage is NOT reliable for file:// pages in some browsers — for safety, click Download CSV or Save session (JSON) whenever you finish a clip, and don't rely solely on auto-save. If you want reliable auto-save AND working seeking, serve this folder with a Range-supporting server (e.g. Node's npx http-server), not Python's http.server.
